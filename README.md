# 🏍️ MotoIA

## Asistente inteligente para diagnóstico de motocicletas

MotoIA es una aplicación web desarrollada con Streamlit que utiliza
Inteligencia Artificial generativa para analizar síntomas descriptos
por los usuarios y generar un diagnóstico mecánico orientativo.

## 🎯 Objetivo

El objetivo de MotoIA es transformar una descripción informal de un
problema mecánico en información estructurada que pueda servir como
orientación inicial para el personal de un taller.

## 🚀 Tecnologías utilizadas

- Python
- Streamlit
- OpenAI API
- GPT-5.6 Luna
- JSON / Structured Outputs
- GitHub

## ⚙️ Funcionamiento

1. El usuario introduce los datos de la motocicleta.
2. Describe el problema que presenta.
3. La aplicación construye un prompt.
4. El prompt es enviado al modelo de Inteligencia Artificial.
5. El modelo devuelve una respuesta estructurada.
6. Streamlit presenta el resultado.

## ⚠️ Limitaciones

MotoIA genera diagnósticos orientativos.

Los resultados no sustituyen la inspección física de una motocicleta
ni el diagnóstico realizado por un mecánico profesional.
